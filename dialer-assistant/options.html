Dialer Assistant

Cellphone → control number data

Import the NEOS cellphones workbook (.xlsx) or a CSV with columns ctrl, CC Cell, REG CELL. The data stays in this browser only. Re-importing replaces the previous data.

Zoiper: look up the caller automatically

In Zoiper: Settings → Automation → Add rule (or, with Show advanced options on, General → Call events → Open URL on: incoming call answer). Set the action to Open URL and paste this, replacing CALLER with Zoiper's caller-number variable (for example $(CALLERNUMBER)):

Zoiper opens that address in your default browser (make Edge the default). The extension sends the number to your open dialer tab, closes the extra tab and shows the control number.
