Caller lookup · automated dispositions · Zoiper hand-off · scheduled time clock

📇Cellphone → control number data

Import the NEOS cellphones workbook (.xlsx) or a CSV with columns ctrl, CC Cell, REG CELL. The data stays in this browser only; re-importing replaces it.

⏰Time clock

Set the automatic clock in / clock out times, days, supervisor in charge and whether to use the dialer's time or this computer's time in the panel's Time Clock tab on the dialer page. It also shows both clocks, a countdown before each event, and Clock in / Clock out now buttons.

💡 Keep Edge running. If no dialer tab is open, the extension opens one a few minutes before a scheduled clock in/out. A desktop notification confirms each one.

📞Zoiper: look up the caller automatically

In Zoiper: Settings → Automation → Add rule (or, with Show advanced options on, General → Call events → Open URL on: incoming call answer). Set the action to Open URL and paste this, replacing CALLER with Zoiper's caller-number variable (for example $(CALLERNUMBER)):

Zoiper opens that address in your default browser (make Edge the default). The extension sends the number to your open dialer tab, closes the extra tab and shows the control number.
