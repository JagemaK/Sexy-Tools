    ai-native engineering
    
I ship like a team, because I work with AI.

    
I treat AI coding agents (Claude Code, ChatGPT) like fast junior engineers. I set the direction, they draft, I review and verify. That's how one self-taught developer ships 10 projects in a year without cutting corners.

    

      
01 / spec
Write it down first
Product spec, data model and a "what's real and what isn't" table before any code, so agents build the right thing.

      
02 / direct
Small, reviewable steps
One focused change per commit. I read every diff, push back, and keep the architecture in my head, not the agent's.

      
03 / verify
Prove it works
Unit, integration and concurrency tests, type checks, and real-browser checks. 175+ test files across my repos.

      
04 / ship
Deploy & document
Vercel, Railway and Render pipelines with migrations on deploy, plus READMEs a new teammate can run in 5 minutes.

    

    
My git history is open about it: many commits are co-authored with Claude. The skill isn't typing code. It's knowing what to build, breaking it down, and catching what's wrong. I bring that from running real operations, not just tutorials.
